# REPOS FOLDER

It is always nice to have a place to put git repos. Yes, you could scatter them all over your file system, but that would be messy and can easily lead to forgetting where anything is. A habit of placing things where the ought to be placed will help you find them in the most obvious place.

"Simplicity is prerequisite for reliability." — Edsger W. Dijkstra
